# E-Commerce Order and Delivery Tracking System

**DBMS case study (III Semester, 2026–2027)** — Stanley College of Engineering & Technology for Women, Hyderabad.

**Team:** Ridah Ahmed (160625733054), Madiha Fatima (160625733039), Manza Fatima Injila (160625733041).

## Project

Educational prototype using **30 historical anonymized Olist order records** (not a production service). The dataset excerpt includes 28 delivered orders, 5 delivered after the estimated date, and 2 not marked delivered. These figures apply to the excerpt only.

Original source: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).

## Demo links

- [Static dashboard](index.html) — browser-based interactive sample; no live database.
- **Published static dashboard:** https://fattokittyo.github.io/ecommerce-order-delivery-tracking/ (GitHub Actions deployment succeeded).
- **Local SQL-backed app:** `app/server.py` with `app/index.html`. This Python 3 web application uses SQLite and loads the sample CSV records into relational tables.
- **MySQL coursework script:** `mysql_schema_and_sample.sql` (separate MySQL 8 database script; not the backend used by the local app).

## Run the local app (Windows)

1. Download the repository ZIP from GitHub → Code → Download ZIP.
2. Extract it on a computer with Python 3 installed.
3. Open the `app` folder and run `start_windows.bat` (or run `python server.py`).
4. Open `http://127.0.0.1:8765` on the **same computer**.

Pages in the local app include dashboard totals, order search, customer/order relationship, late deliveries, follow-up records, read-only SQL console and schema inspection. The follow-up records are locally created demonstration data; the original Olist orders are not changed. Do not expose the local server directly to the internet.
